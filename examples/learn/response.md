# Attention 里的 softmax：为什么饱和，为什么除以 √d

**我的假设**：按标准深度讲（理论概念类），默认你熟悉 Transformer 和反向传播基础；这一课没有运行任何代码，所以数字都标"推导"，不标"已验证"。文献只凭记忆引用，一律写"凭记忆，未核对"。

---

## 1. 原始设计：要解决什么问题

Attention 要做"软查找"：每个 query 对所有 key 打分，用 softmax 变成权重，再加权求和 value。打分最自然的选择是点积 $s = q\cdot k$。

问题出在点积的**尺度会随维度 d 变大**。原始 Transformer 论文（Vaswani et al. 2017，凭记忆，未核对）的说法大意是：d 大时点积幅度变大，把 softmax 推进梯度极小的区域，所以要除以 √d。此前常见的两种打分是加性注意力（小前馈网络，不随 d 增大）和不缩放的点积（算得快，但 d 大时表现更差，论文称观察到这一点，凭记忆，未核对）。缩放点积保留了点积的速度，又修掉了尺度问题。

## 2. 数学原理

### 2.1 先看直觉：softmax 在"放大"差距

softmax 对 logits 做 $e^{z}$ 再归一化，差距是被指数放大的。logits 整体乘以一个大系数，等价于降低温度：分布越来越像 one-hot。one-hot 的位置，输出对输入几乎不敏感，梯度就没了。

### 2.2 小数字例子

取 $z=[1,2,3]$：

- $e^z=[2.718,\ 7.389,\ 20.086]$，和 30.193
- $p=[0.090,\ 0.245,\ 0.665]$（推导）

同样的排序，整体放大 10 倍 $z=[10,20,30]$：

- $p_3=1/(1+e^{-10}+e^{-20})\approx 0.99995$，$p_2\approx 4.5\times10^{-5}$，$p_1\approx 2\times10^{-9}$（推导）

### 2.3 梯度：饱和到底伤在哪

softmax 的雅可比：

$$\frac{\partial p_i}{\partial z_j}=p_i(\delta_{ij}-p_j)$$

对任意上游梯度 $g=\partial L/\partial p$，传到 logits 的梯度是

$$\frac{\partial L}{\partial z_j}=p_j\Big(g_j-\sum_i p_i g_i\Big)$$

读法：**每个 logit 收到的梯度都带一个因子 $p_j$**。one-hot 时，赢家的 $p(1-p)\to0$，输家的 $p_j\to 0$，整个雅可比趋近 0。

把 $[1,2,3]$ 乘以系数 c，看雅可比最大对角元（推导，手算）：

| 系数 c | $p_{\max}$ | 最大对角元 $p(1-p)$ |
|---|---|---|
| 1 | 0.665 | 0.223 |
| 3 | 0.950 | 0.047 |
| 10 | 0.99995 | 0.000045 |

这里有两个后果，不要混为一谈：

1. **梯度整体变小**（上表）。
2. **梯度有偏**：权重低的 key 收到的梯度正比于它自己的 $p_j$。一个当前被忽略的 token，哪怕它才是正确答案，也几乎得不到"把我提上来"的信号。饱和之后，模型很难自己爬出来。

这也说明"梯度小"不等于"学不动"：value 路径和残差路径的梯度仍在。受影响的是**"看哪里"的学习**。

### 2.4 为什么点积会变大：方差推导

**假设**（先说清楚）：q、k 的各分量相互独立，均值 0，方差 1。

- $s=\sum_{i=1}^d q_ik_i$，每一项均值 0，方差 $E[q_i^2]E[k_i^2]=1$
- 各项独立，所以 $\mathrm{Var}(s)=d$，标准差 $\sqrt d$（推导，上述假设下）

所以 logits 的典型幅度是 $\sqrt d$：

| d | 打分标准差 |
|---|---|
| 16 | 4 |
| 64 | 8 |
| 128 | ≈11.3 |
| 1024 | 32 |

再联系 2.2：$[10,20,30]$ 正好相当于"d=100 的未缩放打分"相对"d=1"放大 10 倍的情形。除以 $\sqrt{100}=10$ 就回到 $[1,2,3]$。

### 2.5 为什么是 √d，不是 d，也不是别的

- 除以 $\sqrt d$：$\mathrm{Var}(s/\sqrt d)=d/d=1$，打分标准差回到 1，**与 d 无关**（推导）。
- 除以 d：方差变成 $1/d$，打分都挤在 0 附近，softmax 趋于均匀，模型选不出重点。这是另一个方向的失败（推导）。
- 标准差 1 本身是约定，不是定理。它只是让 logits 落在 softmax 既能区分、又不饱和的量级。方差取 1 还是 2，从这个推导里分不出来。

**这个推导的适用范围**：它解释的是**初始化时的设计动机**，不保证训练中的真实行为（见第 3 节）。

## 3. 设计限制

1. **独立同分布假设不成立。** 真实的 q、k 是 $W_Q x$、$W_K x$，输入 x 的分量相关，权重训练后分布变化，分量不是单位方差、不独立。√d 只是在初始化附近把尺度"校准"。
2. **训练中 logits 会重新长大。** $W_Q,W_K$ 的范数可以增长，缩放系数是固定常数，管不住这一点。训练后期出现 attention 熵坍塌、logit 爆炸一类不稳定，凭记忆有相关工作（例如 Zhai et al. 2023 讨论注意力熵坍塌，未核对原文），这属于第 2 节推导管不到的部分。
3. **序列长度 n 没进公式。** 只考虑 d；n 变大时，最大的那个 logit 本身也会变大（独立高斯下，最大值约 $\sigma\sqrt{2\ln n}$，推导，粗略）。长上下文里，同一套缩放可能不够，或需要随 n 调整。
4. **低精度。** 在 bf16/fp16 下 logits 大了，softmax 前减最大值能防溢出，但"精度不够区分接近的大 logit"是另一回事。这里是我的推测，未测试。

**与后训练的关系（推测，未测试）**：做 RL/偏好优化时学习率与数据分布和预训练不同，如果某些头的 logit 范数被拉大，饱和会让这些头的"看哪里"更难被微调；训练端与推理端的数值差异也可能在饱和区被放大。这些是值得检查的假设，我没有证据说它们在你的模型里成立。

## 4. 改进：各自修什么，付出什么

| 方法 | 修什么 | 代价 / 注意 |
|---|---|---|
| 缩放点积 $1/\sqrt d$ | 初始化时的方差随 d 增长 | 管不住训练中的增长 |
| QK-Norm（对 q、k 做归一化再点积；凭记忆有 Henry et al. 2020 等，未核对） | 直接限制 logit 范数，抗训练期增长 | 多一步归一化；通常要配可学习的缩放 |
| Logit soft-capping（如 tanh 截断；凭记忆有模型使用，未核对） | 硬限 logit 上界 | 截断改变函数形状，影响表达力 |
| 可学习温度 / 随 n 的缩放（如 log n 缩放；凭记忆，未核对） | 让尺度适应长度或任务 | 引入新参数，稳定性待验证 |
| μP 里改用 $1/d$（凭记忆，未核对） | 在宽度扩展下保持超参可迁移 | 初始化与 $1/\sqrt d$ 不同，需配套设置 |
| Sigmoid / 其他非 softmax 注意力（凭记忆，未核对） | 去掉"归一化到 1"的竞争 | 权重不再和为 1，需要额外的偏置/归一化 |
