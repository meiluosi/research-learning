## 发现的问题

**问题 1（第 4 条）：0.99 对应的值写错了。**
a(1−a) 在 a=0.99 时是 0.99×0.01 = **0.0099**，不是 0.009。表里其他五项（0.09、0.21、0.25、0.09、0.000999）都对。公式 a_i(1−a_i) 本身也对（对 softmax 的对角偏导做了有限差分，吻合）。另外这张表有个值得点出的规律：0.1 和 0.9 都是 0.09，函数关于 a=0.5 对称，这正是"权重趋近 0 或 1 时梯度消失"的来源。

**问题 2（第 8 条）：实验设计无法区分 C 和 D，"预期不同"不成立。**
- 第 7 条已经说明了两者等价：RMSNorm(q) = q/rms(q) = √d · q/‖q‖ = √d·q̂（无可学习参数、无 epsilon）。所以 D = (√d q̂)(√d k̂)ᵀ/√d = √d·q̂·k̂ᵀ，正好就是 C。
- 实测：Q、K 放大 1、10、100 倍时，C 和 D 的分数矩阵逐元素相同（最大差 0），标准差都是 0.9922（d=64、n=128，随机高斯输入，所以略小于 1）。两者对放大倍数也完全不敏感。
- 作为对照，普通的 QKᵀ/√d 在放大 100 倍后标准差从 1.01 变成 10118（放大倍数的平方，因为 Q、K 各乘一次）。所以这个实验真正能区分的是"有归一化"和"没归一化"，而不是 C 和 D。
- 修改建议：要么把预期改成"C 与 D 相同，二者都对放大不敏感，只有无归一化的基线会爆炸"，并把基线（A：QKᵀ，B：QKᵀ/√d）放进比较；要么如果想比较 C 和 D 的差异，必须引入会让它们不等价的因素，例如 RMSNorm 带 epsilon 或可学习的缩放参数（此时差异来自这些因素，要在实验里把它们作为被改变的单一变量）。
